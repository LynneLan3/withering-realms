# Withering Realms Steam Deck Key Bindings

Quick answer — Update to 0.36 or later. Patch 0.36 restored the Key Bindings editor on Steam Deck. (CONFIRMED_OFFICIAL)

## What changed in 0.36
Patch 0.36 (released 2026-09-09) explicitly restored the Key Bindings editor on Steam Deck — CONFIRMED_OFFICIAL. Primary source: Steam patch notes / SteamDB for 0.36. Research checked: 2026-09-10. Early Access Steam release: 2026-09-04.

## What to do
1. Make sure your Steam Deck is online and Steam is allowed to update installed games.  
2. Update Withering Realms to build 0.36 or a later build via Steam.  
3. After the update finishes, launch the game and open the game’s settings/menu and select Key Bindings. The editor should now appear.  
4. If the editor still looks missing, close the game and relaunch it once after the update.

## What not to do
- Do not assume Steam Input overlays, desktop-mode remaps, or third‑party tools are required on 0.36+. The official patch restored the in-game editor.  
- Do not follow community “workaround” instructions as mandatory steps for this specific 0.36+ restoration.

## If this didn't work
1. Confirm the installed build is 0.36 or later. Verify via Steam/SteamDB or the game's patch notes (CONFIRMED_OFFICIAL).  
2. Fully restart the game and, if convenient, reboot the Steam Deck after updating.  
3. If the game is confirmed 0.36+ and the Key Bindings editor is still missing, treat the issue as NEEDS_VERIFICATION: gather the build/version shown by Steam, a brief description, and (if possible) a screenshot, then report on the game's official support/bug report channels or the Steam discussion thread so the developers can investigate.
