# Withering Realms — Bellflower Occult Institute Code Words Puzzle

## Quick Answer

- There is no single universal basement password — the Bellflower Occult Institute basement code is randomized (PLAYER_REPORTED).  
- Solve it by reading the code as book-number → word-number pairs (each pair tells you which word to pull from which book). Example format: 1-6 = Book 1, word 6 (example only; not a universal password).  
- Confirm the current book order on the institute’s upper floor (the blackboard/board shows the book order) before extracting words.  
- The bathroom stall clue is written in blood on the floor; count the dots and use those numbers for Book 1’s word numbers when the clue points there (PLAYER_REPORTED).

## How Book-Word Order Works

- The code on the basement door is read as book number → word number. Each pair points to a specific word in a specific book. Example method (for clarity only):  
  - 1-6 = Book 1, word 6  
  - 2-3 = Book 2, word 3  
- Do not treat any concrete word sequences you find online as a guaranteed solution for your game; players report the code is randomized (PLAYER_REPORTED).  
- Players in the discussion reported one observed book-order labeling as Book 1 = Raum, Book 2 = Glasya, Book 3 = Astaroth — present here only as player-reported examples of names seen on the board, not as canonical lore or a universal order (PLAYER_REPORTED).

## Where to Find the Book Order

1. Go to the institute’s upper floor.  
2. Look for the board/blackboard that lists the books or shows the current order — players report the upper-floor board displays the book order you must use (PLAYER_REPORTED).  
3. Note the exact order and any names shown there before you return to the basement puzzle. Do not assume the order from someone else’s screenshot or forum post; confirm it in your own game.

## How to Solve the Bathroom Code

- The bathroom stall clue is written in blood on the floor (PLAYER_REPORTED). The intended method reported by players is to count the dots.  
- Use the dot counts as numbers that correspond to Book 1’s word numbers. Example (method only): if you count 3 dots, then one of the Book 1 positions to use is word 3.  
- Steps:  
  1. Enter the bathroom stall with the blood-marked floor.  
  2. Count the distinct dots carefully (don’t include accidental stains).  
  3. Record those numbers in order — those numbers map to word positions within whatever book is currently Book 1 (as shown on the upper-floor board).

## How to Solve the Basement Code

Follow these steps in player order:

1. Confirm book order upstairs: read the board/blackboard on the upper floor and write down which book is Book 1, Book 2, Book 3 (PLAYER_REPORTED evidence says the board shows the order).  
2. Use the bathroom clue (if present): count the dots on the bathroom stall floor and note those numbers as Book 1 word positions (PLAYER_REPORTED).  
3. Locate the physical books indicated by the board order and open each book to the word index or simply count words in the book text to find the number-th word for each pair. Example interpretation: a code pair 2-3 means “from the book currently labeled Book 2, take word number 3.” (This is the reading method; actual pairs will vary per game.)  
4. Enter the words into the basement door/panel in the exact sequence the puzzle requires (follow the UI prompt in your game).  
5. If the door rejects your input, re-check: the upper-floor board for book order, your dot counts in the bathroom, and make sure you counted words in the correct book and in the correct order. Repeat the steps above — the puzzle is randomized per game instance (PLAYER_REPORTED).

## Why Online Codes May Not Match Your Game

- Players report the basement code is randomized, so a code posted online will often not match your playthrough (PLAYER_REPORTED). Never assume an online string is universal.  
- Some forum posts show concrete examples (for example: “RAUM 3 2 1” or “RAUM 1 GLASYA 5 4”) — those are examples players have seen or posted, not guaranteed answers for everyone. Do not use them as a universal solution.

## Common Mistakes

- Using another player’s full code without checking your own upper-floor book order.  
- Misreading pair format (treating the pair as word→book instead of book→word). The correct reading is book number → word number.  
- Failing to confirm the board upstairs before extracting words from books.  
- Miscounting the bathroom dots or including unrelated floor stains as dots.  
- Assuming book names or order are fixed across all games — player reports show order is something you must confirm in your own run (PLAYER_REPORTED).
